# QuickQr
برنامج QuickQR: أداة خفيفة ومجانية لسطح المكتب لقراءة وتوليد رموز الـ QR والباركود من شاشة الكمبيوتر مباشرة بضغطة زر أو بالتحديد بالماوس، مع حفظ السجل وفتح الروابط تلقائياً.  ⚠️ تنبيه: يُرجى قراءة ملف الـ README.md المرفق لمعرفة التعليمات الهامة ولضمان ضبط لغة المدخلات بالإنجليزية عند تحويل الروابط لكيو أر كود ليعمل بنجاح.
